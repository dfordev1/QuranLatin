Read and build with transliterated Quran translations.

QuranLatin is a JSON library for people who want Quran translation text in Latin letters. It is useful for search, apps, study tools, and readers who cannot comfortably read every original script.

What this is

Translation text rewritten in Latin letters.
Ready-to-use JSON grouped by language.
Quality labels included for every file.

What this is not

Not Arabic recitation transliteration.
Not a new Quran translation.
Not a scholarly final edition for every language.
