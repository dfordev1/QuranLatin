# QuranLatin

Latin-only Quran translation transliteration datasets.

This repository currently publishes Bengali Quran translation text rendered into
Latin script. It does not include Arabic/Persian/Urdu script renderings, and it
does not contain Arabic recitation transliteration.

## Bengali v1

The Bengali package contains five ayah-level translation sources and one
word-by-word source.

### Combined Files

- [Combined JSON](data/bengali/combined/bengali_translations_latin_v1.json)
- [Combined CSV](data/bengali/combined/bengali_translations_latin_v1.csv)

The combined files contain 31,180 rows: 6,236 ayahs across 5 Bengali
translation sources.

### Per-Source Files

Each source has a separate JSON and CSV under [data/bengali/sources](data/bengali/sources).

- `rawai_al_bayan_latin_v1`
- `sheikh_mujibur_rahman_latin_v1`
- `taisirul_quran_latin_v1`
- `dr_abu_bakr_muhammad_zakaria_latin_v1`
- `fathul_majid_latin_v1`

Each per-source file contains 6,236 ayah rows.

### Word-by-Word Files

- [Word-by-word JSON](data/bengali/word_by_word/bengali_word_by_word_latin_v1.json)
- [Word-by-word CSV](data/bengali/word_by_word/bengali_word_by_word_latin_v1.csv)

The word-by-word files contain 83,664 entries.

## Fields

`latin_iast` is generated from Bengali script into Latin letters with diacritics.

`latin_ascii` is generated by stripping diacritics from `latin_iast` for app,
search, and indexing use.

## Notes

These are computational transliterations of Bengali translation text. They are
not Arabic recitation transliterations, and they should be reviewed before being
described as final scholarly transliteration data.

See [manifest.json](manifest.json) for hashes, source names, and coverage.
